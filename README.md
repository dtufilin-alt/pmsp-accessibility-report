# Повышение доступности первичной медико-санитарной помощи

Публичный сайт-отчет проекта ФГБУ «ЦНИИОИЗ» Минздрава России по повышению доступности первичной медико-санитарной помощи в субъектах Российской Федерации.

Период отчета: 2022–2026.

## Рабочее правило проекта

Коммиты и push в удаленный репозиторий выполняются только после двойного подтверждения:

1. ОК от Дениса.
2. ОК от Марии.

До получения обоих подтверждений работа ведется локально: можно готовить структуру, тексты, верстку, README и материалы, но не фиксировать изменения в Git и не отправлять их в GitHub.

## Структура сайта

- `index.html` — главная страница публичного отчета.
- Типовая программа доступна для скачивания с главной страницы (`index.html`) из файла `downloads/tipovaya-programma-pmsp-2025.docx`.
- `style.css` — общие стили сайта.
- `assets/` — изображения, иконки и дополнительные материалы.
- `assets/materials/` — документы, презентации, методические материалы и другие файлы, которые будут добавлены позже.

## Публикация через GitHub Pages

1. Откройте настройки репозитория на GitHub.
2. Перейдите в **Settings → Pages**.
3. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**;
   - Branch: **main**;
   - Folder: **/** root.
4. Нажмите **Save**.
5. После публикации сайт будет доступен по адресу `https://<github-user>.github.io/pmsp-accessibility-report/`.

## Обновление сайта

1. Измените нужные HTML/CSS-файлы или добавьте материалы в `assets/materials/`.
2. Сделайте commit и push в ветку `main`.
3. GitHub Pages автоматически обновит опубликованную версию сайта.

## Что нужно дополнить перед финальной публикацией

- Точный email контактной команды проекта.
- Официальный сайт организации или страницы проекта.
- Ссылки на социальные сети, если их нужно публиковать.
- Актуальность файла типовой программы: `downloads/tipovaya-programma-pmsp-2025.docx`.
- Перечень дополнительных партнеров, если они должны быть указаны.
- При необходимости — официальные изображения, логотипы и иллюстрации.
